# 🎬 Video-Templates für Short-Form Content

> Fertige Strukturen für TikTok, YouTube Shorts & Instagram Reels.

---

## Format-Spezifikationen

| Plattform | Auflösung | Max. Länge | Ideale Länge | Seitenverhältnis |
|---|---|---|---|---|
| **TikTok** | 1080×1920 | 10 min | 15-60 Sek. | 9:16 |
| **YouTube Shorts** | 1080×1920 | 60 Sek. | 30-60 Sek. | 9:16 |
| **Instagram Reels** | 1080×1920 | 90 Sek. | 15-30 Sek. | 9:16 |

---

## Template 1: "Quick Take" (15-30 Sek.)

> Schnelle Meinung oder Fakt zu einem Thema.

```
[0-2s]   HOOK — Provozierende Frage oder Statement
                Avatar: Direkter Blickkontakt, selbstbewusst
                Text-Overlay: Hook in Bold

[2-5s]   SETUP — Kontext geben
                Avatar: Erklärende Gestik
                B-Roll oder Bild-Einblendung

[5-20s]  MAIN POINT — Der eigentliche Inhalt
                Avatar: Engagiert, Emotionen zeigen
                Grafiken/Texte unterstützend

[20-25s] PUNCH — Pointe oder Zusammenfassung
                Avatar: Ausdruck wechseln (Überraschung/Cool)

[25-30s] CTA — Call to Action
                Avatar: Peace-Zeichen / Winken
                Text: "Follow für mehr!" / Frage stellen
```

## Template 2: "Erklär mal" (30-60 Sek.)

> Etwas in unter einer Minute erklären.

```
[0-3s]   HOOK — "Wusstest du, dass...?" / "Das versteht niemand..."
                Avatar: Überraschte/neugierige Expression

[3-10s]  PROBLEM — Was ist die Frage/das Problem?
                Avatar: Nachdenklich
                Visuell: Problem darstellen

[10-40s] ERKLÄRUNG — Schritt für Schritt
                Avatar: Enthusiastisch, zeigend
                Split-Screen oder Grafiken neben Avatar

[40-50s] AHA-MOMENT — "Und DAS ist der Trick!"
                Avatar: Mind-Blown Expression + Glow-Effekt
                Sound Effect + Zoom

[50-60s] ZUSAMMENFASSUNG + CTA
                Avatar: Cool/selbstbewusst
                Text-Overlay mit Key-Takeaway
```

## Template 3: "Reaction" (15-45 Sek.)

> Auf Trends, News oder andere Inhalte reagieren.

```
[0-2s]   TEASER — Kleiner Ausschnitt des Contents
                Avatar: Klein in der Ecke, beobachtend

[2-5s]   SETUP — "Schaut euch DAS an..."
                Avatar: Aufmerksam, gespannt

[5-30s]  REACTION — Inhalt abspielen + Live-Reaktion
                Avatar: Wechselnde Expressions!
                 → Überrascht → Lachend → Mind-Blown

[30-40s] TAKE — Eigene Meinung dazu
                Avatar: Vollbild, direkt in die Kamera
                Eigene Perspektive/Analyse

[40-45s] CTA — Meinung erfragen
                Text: "Was sagt ihr dazu?" / "Team A oder B?"
```

## Template 4: "Tutorial / How-To" (45-60 Sek.)

> Kurze Anleitung für etwas Spezifisches.

```
[0-3s]   HOOK — Ergebnis zuerst zeigen!
                "So machst du [ERGEBNIS] in 60 Sekunden"

[3-8s]   VORHER — Ausgangslage zeigen
                Avatar: "Okay, wir starten hier..."

[8-45s]  SCHRITTE — Numbered Steps
                Schritt 1: [Aktion] → Ergebnis
                Schritt 2: [Aktion] → Ergebnis
                Schritt 3: [Aktion] → Ergebnis
                Avatar: Begleitet jeden Schritt

[45-55s] ERGEBNIS — Fertiges Ergebnis zeigen
                Avatar: Stolz/Excited Expression
                Vorher/Nachher-Vergleich

[55-60s] CTA — "Speichern für später!" + Follow
```

## Sound & Musik Richtlinien

| Element | Empfehlung |
|---|---|
| **Hintergrundmusik** | Trending Sounds / Lizenzfrei (Epidemic Sound, Artlist) |
| **Sound Effects** | Whoosh, Pop, Ding für Übergänge |
| **Stimme** | Klar, energisch, nah am Mikro |
| **Lautstärke-Mix** | Stimme -3dB / Musik -18dB / SFX -12dB |

## Posting-Strategie

| Aspekt | Empfehlung |
|---|---|
| **Frequenz** | 3-5 Videos pro Woche |
| **Beste Zeiten** | 12:00-14:00 und 18:00-21:00 |
| **Hashtag-Strategie** | 3-5 relevante + 1-2 Nischen-Tags |
| **Cross-Posting** | Gleiches Video auf allen 3 Plattformen |
