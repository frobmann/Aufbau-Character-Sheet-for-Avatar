## Video-Branding

### Intro (2-3 Sekunden)

```
[Animiertes Logo / Avatar-Pose]
→ Soundeffekt / Jingle (max 2 Sek.)
→ Übergang zum Content
```

> Kurz halten! Bei Shorts zählt jede Sekunde.

### Outro (3-5 Sekunden)

```
[Avatar winkt / Peace-Zeichen]
→ "Follow für mehr!" + Social-Handle
→ Logo-Animation
→ Endscreen (nur YouTube)
```

### Wasserzeichen / Overlay

| Element | Position | Größe | Transparenz |
|---|---|---|---|
| **Logo** | Unten rechts | 5-8% des Screens | 50-70% |
| **Social Handle** | Oben links (optional) | Klein | 60% |

| **Position** | Unteres Drittel, mittig |
