# 🎨 Visuelles Design

> Das Aussehen deines Avatars — von Kopf bis Fuß.

---

## Kopf & Gesicht

| Merkmal | Beschreibung | Notizen |
|---|---|---|
| **Gesichtsform** | Oval | Gleichmäßig, vielseitig — gute Basis für Expressions |
| **Augenfarbe** | Warmbraun `#8B6914` | Natürliche Basis; subtiler Bernstein-Shift als Fantasy-Element (siehe unten) |
| **Augenform** | Mandelförmig | Ausdrucksstark, funktioniert gut für übertriebene Emotionen in Shorts |
| **Augenbrauen** | Mittel, natürlich geschwungen | Wichtig für Expressions — müssen gut animierbar sein |
| **Nase** | Gerade, mittlere Größe | Proportional zur ovalen Gesichtsform |
| **Mund / Lippen** | Mittel, leichtes Default-Lächeln | Ruhender Gesichtsausdruck = leicht freundlich |
| **Hautton** | Mittel / Medium `#C8A882` | Warmer Unterton, leicht gebräunt |
| **Besondere Merkmale** | Keine (clean look) | Klarheit = bessere Wiedererkennbarkeit |

## Haare

| Merkmal | Beschreibung |
|---|---|
| **Frisur** | Mittellang, leicht strukturiert/texturiert — seitlich oder nach hinten gestylt, nicht zu streng |
| **Haarfarbe** | Dunkelbraun `#3B2314` — natürlich, tief |
| **Besonderheiten** | Leichter Glanz / Lichtreflexe bei Bewegung (hilft bei 3D-Rendering). Optional: einzelne dunklere/hellere Strähnen für Tiefe |

## Körper

| Merkmal | Beschreibung |
|---|---|
| **Körperbau** | Durchschnitt — weder besonders breit noch schmal |
| **Größe** | Mittlere Proportionen (in Shorts meist nur Oberkörper sichtbar) |
| **Proportionen** | Leicht stilisiert (Stufe 3-4) — erkennbar als Person, aber cleaner als Realität |
| **Haltung** | Aufrecht-entspannt — selbstbewusst aber nicht steif |

## Fantasy/Kreative Elemente

> **Ansatz: Minimalistisch & Subtil** — Auf den ersten Blick sieht der Avatar fast realistisch aus. Erst beim genaueren Hinschauen oder bei bestimmten Momenten zeigen sich die besonderen Elemente.

### Element 1: Augen-Shift ✨
| Aspekt | Detail |
|---|---|
| **Was** | Die Augen wechseln bei starken Emotionen subtil die Farbe — von warmem Braun zu Bernstein/Gold `#D4A017` |
| **Wann** | Bei Überraschung, Begeisterung oder "Mind Blown"-Momenten |
| **Wie stark** | Sanfter Verlauf über 0.5 Sekunden, kein greller Glow — eher wie Sonnenlicht, das durch Honig scheint |
| **Animierbar** | ✅ Ja — Farbshift als Blendshape-getriebener Material-Wechsel |

### Element 2: Signatur-Accessoire
| Aspekt | Detail |
|---|---|
| **Was** | Ein einzelnes, markantes Accessoire — zum Beispiel: |
| | → **Option A:** Ein schlichter Ring mit einem schwach leuchtenden Linienmuster |
| | → **Option B:** Ein minimalistisches Armband, das bei bestimmten Gesten kurz aufleuchtet |
| | → **Option C:** Ein kleiner Ohrring/Ear Cuff mit geometrischem Design |
| **Stil** | Modern-dezent, kein offensichtliches Fantasy-Schmuckstück — eher wie ein gut designtes Tech-Produkt |
| **Animierbar** | ✅ Ja — schwaches Pulsieren oder Aufleuchten in Highlight-Momenten |

### Element 3: Subtile Partikel (Optional, für besondere Momente)
| Aspekt | Detail |
|---|---|
| **Was** | Winzige, kaum sichtbare Lichtpartikel, die kurz um den Avatar erscheinen |
| **Wann** | Nur bei "Peak-Momenten" — Intro, Outro, oder emotionalen Höhepunkten |
| **Wie stark** | Extrem dezent — wie Staubkörner im Sonnenlicht, nicht wie ein Feuerwerk |
| **Farbe** | Warm-Gold `#D4A017` passend zum Augen-Shift |

## Stilrichtung

> Leicht stilisiert — erkennbar als echte Person, aber idealisiert und geglättet.

```
Realistisch ──────────────────────── Stilisiert
         1    2    3    4    5    6    7
                   ↑
              Stufe 3-4
```

**Beschreibung:** Wie eine hochwertige 3D-Figur in einem modernen Animationsfilm (z.B. Stil-Richtung "Into the Spider-Verse" Realismus, oder Fortnite-Skins auf der realistischeren Seite). Gesichtszüge sind erkennbar "du", aber cleaner, mit ausdrucksstärkeren Augen und leicht vereinfachten Details.
