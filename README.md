# 🎭 Avatar Character Sheet

> Persönliches Character Sheet für die Erstellung eines 3D-Avatars und Social-Media-Video-Produktion.

## Projektübersicht

Dieses Repository enthält alle Design-Dokumente, Referenzen und technischen Spezifikationen für meinen personalisierten 3D-Avatar — eine stilisierte Version von mir selbst mit kreativen/Fantasy-Elementen.

**Ziel:** Einen wiedererkennbaren 3D-Avatar erstellen, der in kurzen Social-Media-Videos (TikTok, YouTube Shorts, Instagram Reels) auftritt.

## 📁 Projektstruktur

```
├── character-sheet/           # Komplettes Character Design
│   ├── 01-identity.md         # Name, Alias, Hintergrund
│   ├── 02-visual-design.md    # Aussehen & Proportionen
│   ├── 03-expressions.md      # Emotionen & Gesichtsausdrücke
│   ├── 04-outfits.md          # Kleidung & Accessoires
│   ├── 05-color-palette.md    # Farbpalette & Codes
│   ├── 06-personality.md      # Persönlichkeit & Auftreten
│   └── 07-technical-specs.md  # 3D-Modell-Spezifikationen
├── production/                # Video-Produktion
│   ├── video-templates.md     # Vorlagen für Short-Form Videos
│   ├── branding.md            # Visuelle Identität & Branding
│   └── tools-software.md     # Software & Pipeline
├── references/                # Referenzbilder & Moodboards
└── assets/                    # 3D-Modelle, Texturen, Exports
    ├── models/
    └── textures/
```

## 🚀 Workflow

1. **Character Sheet ausfüllen** → Alle Design-Entscheidungen dokumentieren
2. **Referenzen sammeln** → Moodboard & Inspirationen in `/references/`
3. **3D-Modell erstellen** → Mit VRoid Studio / Blender
4. **Rigging & Animation** → Gesichtsausdrücke & Bewegungen
5. **Video-Pipeline aufsetzen** → Tools für Short-Form Content
6. **Content produzieren** → Videos erstellen und veröffentlichen
